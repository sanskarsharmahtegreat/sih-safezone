# SAFEZONE — SIH Disaster Response Prototype

## Run
Install Node.js 18+.

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Demo
1. Start in Admin mode.
2. Click **Simulate Flood**.
3. Watch the risk zone, blocked road, rescue teams and dashboard counters appear.
4. Click **Open Shelter** and create a new emergency shelter.
5. Switch to **Citizen**.
6. Click **Find Safe Route**.

## Stack
React + Vite + Leaflet + OpenStreetMap + Lucide React.

No API key or paid service is required.

## Prototype note
Disaster events, population, blocked roads, response teams and evacuation paths are simulated data for the SIH demonstration.
